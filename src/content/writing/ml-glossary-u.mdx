## Undersampling: Let the Crowd Shrink

<Convo
  lines={[
    { who: 'cherry', text: 'Last time I oversampled the rare class. What if I go the other way?' },

## Unidirectional Language Model: Only Looking Left

<Convo
  lines={[
    { who: 'cherry', text: 'I type I went to the, and my keyboard guesses the next word. It does not know how my sentence ends.' },

    { who: 'sundu', text: 'In I went to the blank to withdraw some money, the end of the sentence is the clue.' },

**Real definition:** a language model that bases its probabilities only on the tokens appearing before, not after, the target token(s). Contrast with bidirectional language model. [Google’s glossary: unidirectional language model ↗](https://developers.google.com/machine-learning/glossary#unidirectional-language-model)

## Unsupervised Machine Learning: Nobody Told It What a Face Is

<Convo
  lines={[
    { who: 'cherry', text: 'What can a model learn when there are no labels at all?' },
    { who: 'sriku', text: 'Unsupervised machine learning trains a model to find patterns in a dataset, typically an unlabeled one. The most common use is to cluster data into groups of similar examples, which is what K-means did in Part K.     { who: 'sundu', text: 'So the model invents its own categories.' },

<Convo
  lines={[

    { who: 'cherry', text: 'How much hardware?' },

  ]}
/>

**Real definition:** training a model to find patterns in a dataset, typically an unlabeled dataset. The most common use of unsupervised machine learning is to cluster data into groups of similar examples. [Google’s glossary (Fundamentals): unsupervised machine learning ↗](https://developers.google.com/machine-learning/glossary/fundamentals#unsupervised-machine-learning)
