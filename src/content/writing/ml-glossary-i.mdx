<Convo
  lines={[
    { who: 'cherry', text: 'My fraud model is 99% accurate. Do I get a bonus?' },
    { who: 'sriku', text: 'How much of the data is fraud?' },
    { who: 'cherry', text: 'About 1%.' },
    { who: 'sriku', text: 'Then "never fraud" is also 99% accurate and catches nothing. You have an imbalanced dataset, a synonym in Google’s glossary for a class-imbalanced dataset.' },
  ]}
/>

<Gif
  name="imbalanced-dataset"

<Convo
  lines={[

    { who: 'sriku', text: 'Chawla, Bowyer, Hall and Kegelmeyer wrote the classic paper on it, SMOTE.     { who: 'cherry', text: 'Just throw away normal examples?' },
    { who: 'sriku', text: 'That under-sampling helps, but they show that combining it with over-sampling the minority class, by creating synthetic minority examples, does better in ROC space.' },
    { who: 'sundu', text: 'Better than other tricks?' },
    { who: 'sriku', text: 'Better than under-sampling alone, better than varying the loss ratios in Ripper and better than varying class priors in Naive Bayes. They tested with C4.5, Ripper and Naive Bayes, judged by AUC and the ROC convex hull.' },
  ]}
/>

<CaseStudy
  title="SMOTE (Chawla et al., 2002)"

  winner="The abstract: a combination of over-sampling the minority class and under-sampling the majority class “can achieve better classifier performance (in ROC space) than only under-sampling the majority class.”"

**Real definition:** a synonym for class-imbalanced dataset, a class-imbalanced dataset is one for a classification in which the total number of labels of each class differs significantly, such as 1,000,000 negative labels against 10 positive ones. [Google’s glossary: imbalanced dataset ↗](https://developers.google.com/machine-learning/glossary#imbalanced-dataset) · [class-imbalanced dataset (Fundamentals) ↗](https://developers.google.com/machine-learning/glossary/fundamentals#class-imbalanced-dataset)

## Intersection over Union (IoU): How Much Do the Boxes Overlap?

<Convo
  lines={[
    { who: 'cherry', text: 'My detector drew a box around the dog, but not exactly where I drew mine. Is it right?' },
    { who: 'sriku', text: 'That is what IoU measures: the intersection of two boxes divided by their union. 0 means no overlap at all, 1 means the same coordinates.' },
    { who: 'sundu', text: 'So the predicted box against the ground-truth box from Part G.' },
    { who: 'sriku', text: 'Yes, and Part B’s bounding box. You then pick an IoU threshold to decide whether a prediction counts as correct.' },
  ]}
/>

<Gif
  name="iou"
  alt="A green rectangle is the ground-truth box and a gold rectangle is the predicted box. The gold box slides over the green one, and a counter shows the IoU rising and passing the 0.5 threshold. A final note says a 10 by 10 object inside a 20 by 20 box has an IoU of 100 over 400, which is 0.25."
  caption="Fig. 82: Slide the prediction. The IoU number is overlap divided by total area."
/>

<Convo
  lines={[
    { who: 'sundu', text: 'Is 0.5 a rule?' },
    { who: 'sriku', text: 'It is the PASCAL VOC convention: a predicted box counts as correct if IoU is at least 0.5. The ImageNet challenge team noticed a problem for tiny objects.' },
    { who: 'cherry', text: 'Which is?' },
    { who: 'sriku', text: 'Take a 10 by 10 pixel object and a 20 by 20 detection window that fully contains it. That is about 5 pixels off on each side, roughly average human annotation error. But the IoU is 100 over 400, which is 0.25, far below 0.5.' },
    { who: 'sundu', text: 'So the fair answer is marked wrong.' },
    { who: 'sriku', text: 'So for smaller objects ILSVRC loosens the threshold, to allow up to about 5 pixels of slack in each direction. In the paper the threshold is the smaller of 0.5 and w·h divided by (w+10)(h+10).' },
  ]}
/>

<CaseStudy
  title="IoU thresholds in ImageNet detection (Russakovsky et al., 2015)"
  stats={[
    { value: '0.5', label: 'PASCAL VOC IoU threshold' },
    { value: '0.25', label: 'IoU of a 10×10 object in a 20×20 box' },
    { value: '~5 px', label: 'Slack allowed per side for small objects' },
  ]}
  winner="The paper’s formula: if the ground-truth box is w by h, the threshold is “min(0.5, wh / ((w+10)(h+10))).”"
  takeaway="A fixed cutoff can be unfair at small scales. Choose the threshold to fit the objects."
  source={{
    text: 'Russakovsky et al., “ImageNet Large Scale Visual Recognition Challenge”, International Journal of Computer Vision, 2015. Free on arXiv.',
    href: 'https://arxiv.org/abs/1409.0575',
  }}
/>

**Real definition:** the intersection of two sets divided by their union. In image detection, IoU measures the accuracy of a predicted bounding box with respect to the ground-truth bounding box, from 0 (no overlap) to 1 (identical coordinates). [Google’s glossary: intersection over union (IoU) ↗](https://developers.google.com/machine-learning/glossary#intersection-over-union-iou)

## I.I.D.: The Ideal Gas of Machine Learning

<Convo
  lines={[
    { who: 'cherry', text: 'The textbook keeps saying "assume the data is i.i.d.". What does that buy me?' },
    { who: 'sriku', text: 'Independently and identically distributed: data drawn from a distribution that does not change, where each value does not depend on the previous ones. Google’s glossary calls it the ideal gas of machine learning.' },
    { who: 'sundu', text: 'Useful, but never exactly true.' },
    { who: 'sriku', text: 'Right. Visitors to a web page may be i.i.d. over a short window, but stretch the window and seasonal differences appear. That is nonstationarity.' },
  ]}
/>

    { who: 'sriku', text: 'On each dataset, standard training gave substantially lower out-of-distribution than in-distribution performance. The gap remained even with existing methods designed to tackle distribution shift.' },
    { who: 'sundu', text: 'So it is not solved.' },

**Real definition:** data drawn from a distribution that does not change, and where each value drawn does not depend on values drawn previously. [Google’s glossary (Fundamentals): independently and identically distributed (i.i.d) ↗](https://developers.google.com/machine-learning/glossary/fundamentals#independently-and-identically-distributed-i.i.d)
