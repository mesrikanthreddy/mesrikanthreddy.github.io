    { who: 'sundu', text: 'So it uses the words on both sides of the blank.' },

<Convo
  lines={[

    { who: 'cherry', text: 'How much gets hidden?' },
    { who: 'sriku', text: 'In all their experiments, 15% of the WordPiece tokens in each sequence, at random. Of the chosen tokens, 80% become the MASK token, 10% become a random token and 10% stay unchanged. The model then predicts the original token.' },

    { who: 'sriku', text: 'New state-of-the-art results on eleven natural language processing tasks, including a GLUE score of 80.5%, a 7.7 point absolute improvement, and SQuAD v1.1 Test F1 of 93.2, up 1.5 points.' },
  ]}
/>

<CaseStudy

## Mixture of Experts: Most of the Model Sleeps

<Convo
  lines={[
    { who: 'cherry', text: 'Bigger models are smarter, but my bill grows with them.' },
    { who: 'sriku', text: 'A mixture of experts is a scheme to increase efficiency by using only a subset of the network’s parameters, called experts, to process each input token or example. A gating network routes each input to the proper expert or experts.' },
    { who: 'sundu', text: 'So most of the model is asleep for any given token.' },
    { who: 'sriku', text: 'That is the trick. Capacity can grow much faster than the compute spent on each token.' },
  ]}
/>

<Gif

  caption="Fig. 99: Toy routing. Two of eight experts wake up for each token."

  lines={[

**Real definition:** a scheme to increase neural network efficiency by using only a subset of its parameters (known as an expert) to process a given input token or example. A gating network routes each input token or example to the proper expert(s). [Google’s glossary: mixture of experts ↗](https://developers.google.com/machine-learning/glossary#mixture-of-experts)

## Chai-Stall Recap

| Term | The chai-stall version | Plain meaning |
| --- | --- | --- |
| Machine translation | Words in, meaning out | Software that converts text between languages |
| Masked language model | Fill in the blank from both sides | Predict hidden tokens using their context |
| Matrix factorization | Two thin matrices fill the gaps | Approximate a matrix, such as ratings, by a dot product |
| Mixture of experts | Most of the model sleeps | A gate sends each token to a few experts |
| MNIST | The hello world of vision | A classic set of handwritten digits |
