## Chai-Stall Recap

| Term | The chai-stall version | Plain meaning |
| --- | --- | --- |
| Candidate generation | The funnel | Cut a huge catalog down to a short list |
| Chain-of-thought prompting | Show your working | Ask the model to reason step by step |
| Checkpoint | Save before you regret | Saved model state to resume from |
| Classification threshold | Where you draw the line | Turns a score into yes or no |
| Collaborative filtering | People like you also bought | Predict taste from many other users |
| Concept drift | The world moved, the model did not | The data relationship changes over time |
| Confabulation | The confident friend | A model confidently saying false things |
| Context window | How much it can remember | Tokens a model can use at once |
| Convolutional neural network | The edge finder | A sliding filter that finds patterns |
