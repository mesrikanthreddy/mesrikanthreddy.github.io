Many natural language understanding models rely on N-grams to predict the next word that the user will type or say. ## Negative Sampling: Score a Few Wrong Answers, Not All of Them

<Convo
  lines={[
    { who: 'cherry', text: 'My model has to pick one word out of a million. Do I really have to score all million every time?' },
    { who: 'sriku', text: 'No. Negative sampling, which Google’s glossary lists as a synonym for candidate sampling, is a training-time optimization. You calculate a probability for all the positive labels, using softmax for example, but only for a random sample of the negative labels.' },
    { who: 'sundu', text: 'Example?' },
    { who: 'sriku', text: 'Given an example labeled beagle and dog, you compute predictions and loss terms for beagle, for dog, and for a random subset of the other classes, say cat, lollipop and fence. The idea is that negative classes can learn from less frequent negative reinforcement, as long as the positive classes always get proper positive reinforcement. The glossary says this is observed empirically.' },
  ]}
/>

  caption="Fig. 102: Toy embedding. Pull the true neighbour in, push a few random words away."
/>

<Convo
  lines={[

## Non-Response Bias: The Silent Ones Still Count

<Convo
  lines={[
    { who: 'cherry', text: 'I sent a survey to all my customers. Only the loud ones replied.' },
    { who: 'sriku', text: 'That is non-response bias, also called participation bias: users from certain groups opt out of surveys at different rates than users from other groups.     { who: 'sundu', text: 'So selection bias is the bigger family.' },

## Normalization: Put Every Feature on the Same Ruler

<Convo
  lines={[
    { who: 'cherry', text: 'One of my features runs from 800 to 2,400 and another from 0 to 1. The model treats them like they are from different planets.' },
    { who: 'sriku', text: 'Normalization, broadly, is converting a variable’s actual range of values into a standard range, such as -1 to +1, 0 to 1, or Z-scores, roughly -3 to +3. Google’s example is yours: a feature that runs from 800 to 2,400 normalized down to -1 to +1.' },
    { who: 'sundu', text: 'Why bother?' },
    { who: 'sriku', text: 'Models usually train faster, and produce better predictions, when every numerical feature in the feature vector has roughly the same range.' },
  ]}
/>

<Gif
  name="normalization"
  alt="A histogram of a feature whose raw values run from 800 to 2,400 slides and rescales until the same shape sits on an axis from minus 1 to 1. A caption cites the batch normalization paper: the same accuracy in 14 times fewer training steps. The data is a toy example."
  caption="Fig. 105: Toy feature. Same shape, friendlier numbers."
/>

<Convo
  lines={[
    { who: 'sundu', text: 'Does it only apply to the input features?' },
    { who: 'sriku', text: 'Ioffe and Szegedy at Google applied the same idea inside the network. They noticed that the distribution of each layer’s inputs changes during training as earlier layers’ parameters change, and they call that internal covariate shift. Batch normalization normalizes the layer inputs for each training mini-batch.' },
    { who: 'cherry', text: 'What did it buy them?' },
    { who: 'sriku', text: 'They could use much higher learning rates and be less careful about initialization. Remember the learning rate from Part L. Applied to a state-of-the-art image classification model, it reached the same accuracy with 14 times fewer training steps.' },
    { who: 'sundu', text: 'And it beat the original model?' },
    { who: 'sriku', text: 'By a significant margin, they say. An ensemble of batch-normalized networks reached 4.9% top-5 validation error, 4.8% on the test set, which the paper says exceeds the accuracy of human raters. It also acts as a regularizer, in some cases removing the need for Dropout.' },
  ]}
/>

<CaseStudy
  title="Batch Normalization (Ioffe and Szegedy, Google, 2015)"
  stats={[
    { value: '14x', label: 'Fewer training steps for the same accuracy' },
    { value: '4.9%', label: 'Top-5 validation error on ImageNet with an ensemble' },
  ]}
  winner="The abstract: “Batch Normalization achieves the same accuracy with 14 times fewer training steps, and beats the original model by a significant margin.”"
  takeaway="Keep the numbers flowing through a network in a friendly range, and you can take bigger steps."
  source={{
    text: 'Ioffe and Szegedy, “Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift”, ICML 2015. Free on arXiv.',
    href: 'https://arxiv.org/abs/1502.03167',
  }}
/>

**Real definition:** broadly speaking, the process of converting a variable’s actual range of values into a standard range of values, such as -1 to +1, 0 to 1, or Z-scores. [Google’s glossary (Fundamentals): normalization ↗](https://developers.google.com/machine-learning/glossary/fundamentals#normalization)
