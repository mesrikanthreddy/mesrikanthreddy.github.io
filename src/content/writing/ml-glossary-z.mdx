**Real definition:** a type of machine learning training where the model infers a prediction for a task that it was not specifically already trained on. In other words, the model is given zero task-specific training examples but asked to do inference for that task. [Google’s glossary: zero-shot learning ↗](https://developers.google.com/machine-learning/glossary#zero-shot-learning)

## Zero-Shot Prompting: One Magic Sentence

<Convo
  lines={[
    { who: 'cherry', text: 'Few-shot prompting from Part F means I have to write good examples. What if I just ask?' },
    { who: 'sriku', text: 'Then you are zero-shot prompting: a prompt that does not provide an example of how you want the large language model to respond. Google’s example asks for the official currency of a country, and the model might answer rupee, INR or the Indian rupee. All are right, but you might prefer one format.' },
    { who: 'sundu', text: 'So it is the cheapest prompt, and the least controlled.' },
    { who: 'sriku', text: 'Yes. Though one small addition turns out to matter a lot for reasoning problems.' },
  ]}
/>
