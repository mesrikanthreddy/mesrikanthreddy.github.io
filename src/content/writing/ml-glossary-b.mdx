## Backpropagation: The Blame Game

<Convo

## Broadcasting: One Pour, Many Cups

<Convo
  lines={[
    { who: 'cherry', text: 'I want to add 10 to every number in a list. Do I need a loop?' },
    { who: 'sriku', text: 'No. Broadcasting. The smaller operand is virtually stretched to a compatible shape, so the operation just works.' },
    { who: 'sundu', text: 'Like pouring one pot of chai into every cup.' },
    { who: 'sriku', text: 'Same pot, many cups. Google’s glossary puts it this way: you cannot add a matrix of shape (m, n) to a vector of length n, and broadcasting makes it work by virtually expanding the vector.' },
  ]}
/>

<Gif
  name="broadcasting"

/>

<Convo
  lines={[
