## Self-Supervised Learning: The Data Makes Its Own Labels

<Convo
  lines={[

    { who: 'sundu', text: 'The masked words in Part M.' },
    { who: 'sriku', text: 'Exactly. The hidden word is the label, and the sentence itself supplies it. For images, you can do something similar with two edited versions of the same photo.' },

## Subword Token: No Word Is Too Rare to Spell

<Convo
  lines={[
    { who: 'cherry', text: 'My translation model panics on rare words and names.' },
    { who: 'sriku', text: 'Use subword tokens. A subword token is a token that is a substring of a word, which may be the whole word. Google’s example splits itemize into item and ize, each with its own token, while a common word like going may stay a single token.' },
    { who: 'sundu', text: 'So a rare word becomes pieces of common words.' },
    { who: 'sriku', text: 'Yes. The language model operates on the word’s more common constituent parts, such as prefixes and suffixes.' },
  ]}
/>

<Gif
  name="subword-token"
  alt="Four toy words, low, lower, newest and widest, start as single characters. The most frequent neighbouring pair is merged step by step, forming es, then est, then est with an end marker, then lo, then low. A caption notes the paper's gains of 1.1 and 1.3 BLEU. The corpus is the small example used in the paper."
  caption="Fig. 126: A tiny corpus. Merge the most frequent pair, repeat."
/>

<Convo
  lines={[
    { who: 'sundu', text: 'How did it enter translation?' },
    { who: 'sriku', text: 'Sennrich, Haddow and Birch pointed out that neural machine translation usually has a fixed vocabulary, but translation is an open-vocabulary problem. They encode rare and unknown words as sequences of subword units, with a segmentation based on the byte pair encoding compression algorithm.' },
    { who: 'cherry', text: 'Why would that work?' },
    { who: 'sriku', text: 'The intuition is that many word classes are translatable via smaller units: names via character copying, compounds via compositional translation, and cognates and loanwords via phonological and morphological transformations.' },
    { who: 'sundu', text: 'And the gain?' },
    { who: 'sriku', text: 'Subword models improved over a back-off dictionary baseline on the WMT 15 tasks by 1.1 BLEU for English-German and 1.3 BLEU for English-Russian.' },
  ]}
/>

<CaseStudy
  title="Neural Machine Translation of Rare Words with Subword Units (Sennrich, Haddow and Birch, 2015)"
  stats={[
    { value: '+1.1 BLEU', label: 'English to German, WMT 15, over a back-off dictionary' },
    { value: '+1.3 BLEU', label: 'English to Russian, WMT 15' },
  ]}
  winner="The abstract: “making the NMT model capable of open-vocabulary translation by encoding rare and unknown words as sequences of subword units.”"
  takeaway="Do not give every rare word its own slot. Spell it from pieces the model already knows."
  source={{
    text: 'Sennrich, Haddow and Birch, “Neural Machine Translation of Rare Words with Subword Units”, 2015. Free on arXiv.',
    href: 'https://arxiv.org/abs/1508.07909',
  }}
/>

**Real definition:** in language models, a token that is a substring of a word, which may be the entire word. [Google’s glossary: subword token ↗](https://developers.google.com/machine-learning/glossary#subword-token)

## SuperGLUE: The Benchmark That Replaced a Too-Easy One

<Convo
  lines={[
    { who: 'cherry', text: 'How do I rate a language model with one score instead of twenty?' },
    { who: 'sriku', text: 'SuperGLUE is an ensemble of datasets for rating an LLM’s overall ability to understand and generate text. It combines BoolQ, CB, COPA, MultiRC, ReCoRD, RTE, WiC and WSC.' },
    { who: 'sundu', text: 'Why the name?' },
    { who: 'sriku', text: 'The paper is called SuperGLUE: A Stickier Benchmark for General-Purpose Language Understanding Systems. It follows GLUE, which came out a little over a year earlier.' },
  ]}
/>

<Gif

  caption="Fig. 127: Eight tasks, and the gap the paper reported."
/>

<Convo
  lines={[

So Wang and colleagues built a benchmark with a new set of more difficult tasks, a software toolkit and a public leaderboard.' },
    { who: 'cherry', text: 'How big was the gap at the start?' },
    { who: 'sriku', text: 'On the test sets, their BERT baseline averaged 69.0, and a stronger BERT variant averaged 71.5. The human estimate was 89.8.' },

<CaseStudy
  title="SuperGLUE (Wang et al., 2019)"
