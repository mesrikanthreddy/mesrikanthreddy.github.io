## Early Stopping: Leave Before the Party Turns

<Convo
  lines={[
    { who: 'cherry', text: 'My training loss keeps going down, but the model got worse on new data an hour ago.' },

## Encoder: Squeeze It Into a Vector

<Convo
  lines={[
    { who: 'cherry', text: 'How does a translation model read a sentence?' },
    { who: 'sriku', text: 'An encoder converts a raw, sparse or external representation into a more processed, denser, internal one. For a sentence, that is a vector.' },
    { who: 'sundu', text: 'And then?' },
    { who: 'sriku', text: 'A decoder takes that internal state and writes the output sequence, one piece at a time. Encoder in, decoder out.' },
  ]}

  lines={[

    { who: 'sundu', text: 'Any odd tricks?' },

  ]}
/>

<CaseStudy
  title="Sequence to sequence learning (Google, 2014)"
  stats={[
    { value: '34.8', label: 'BLEU, LSTM encoder-decoder, English to French' },

  source={{

**Real definition:** in general, any ML system that converts from a raw, sparse or external representation into a more processed, denser or more internal representation. Encoders are often paired with a decoder. [Google’s glossary: encoder ↗](https://developers.google.com/machine-learning/glossary#encoder)

<Convo
  lines={[

## Exploding Gradient Problem: The Cliff

<Convo
  lines={[
    { who: 'cherry', text: 'My loss went to NaN overnight.' },
    { who: 'sriku', text: 'Classic. The exploding gradient problem is when gradients in deep networks, especially recurrent ones, become surprisingly steep, which causes enormous updates to the weights.' },
    { who: 'sundu', text: 'The model jumps off the map.' },
    { who: 'sriku', text: 'Models suffering from it become difficult or impossible to train. The usual fix is gradient clipping.' },
  ]}
/>

<Gif
  name="exploding-gradient"
  alt="A flat path ends at a steep wall. A red arrow from the model, which stands at the foot of the wall, shoots far off the map. A short green arrow in the same direction shows the clipped step. The picture is a toy illustration."
  caption="Fig. 49: Toy picture. Same direction, but the step is capped."
/>

<Convo
  lines={[
    { who: 'sundu', text: 'Who explained it?' },
    { who: 'sriku', text: 'Pascanu, Mikolov and Bengio, in 2013. They analyzed why recurrent networks are hard to train, with a geometric picture of high-curvature walls in the error surface.' },
    { who: 'cherry', text: 'And the cure?' },
    { who: 'sriku', text: 'Rescale the gradient whenever its norm goes above a threshold. In their experiments training was not very sensitive to the threshold, and it worked even with rather small ones.' },
    { who: 'sundu', text: 'Is it a regularizer?' },
    { who: 'sriku', text: 'They say it solves an optimization issue, because both training and test error improve. On Penn Treebank language modelling it reached the state of the art achieved by Mikolov et al.' },
  ]}
/>

<CaseStudy
  title="Gradient norm clipping (Pascanu, Mikolov and Bengio, 2013)"
  stats={[
    { value: '1', label: 'Extra hyperparameter: the threshold' },
    { value: 'Both', label: 'Training and test error improve' },
  ]}
  winner="In their words: “We propose a gradient norm clipping strategy to deal with exploding gradients.”"
  takeaway="You do not have to change the model. Limit how far one bad step can take it."
  source={{
    text: 'Pascanu, Mikolov and Bengio, “On the difficulty of training Recurrent Neural Networks”, ICML 2013. Free on arXiv.',
    href: 'https://arxiv.org/abs/1211.5063',
  }}
/>

**Real definition:** the tendency for gradients in deep neural networks (especially recurrent neural networks) to become surprisingly steep, which often causes very large weight updates. Gradient clipping can mitigate it. [Google’s glossary: exploding gradient problem ↗](https://developers.google.com/machine-learning/glossary#exploding-gradient-problem)

## Experience Replay: Shuffle the Memories

<Convo
  lines={[
    { who: 'cherry', text: 'My game-playing agent only learns from what it did a second ago.' },
