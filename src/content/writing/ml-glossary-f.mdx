<Convo
  lines={[
    { who: 'cherry', text: 'Everyone keeps saying "foundation model". Is that just a big model?' },

    { who: 'sundu', text: 'Why "foundation"?' },

## Forget Gate: Remember What Matters

<Convo
  lines={[
    { who: 'cherry', text: '"The cat, which ate quickly, was hungry." How does a model keep "cat" in mind until it reaches "was"?' },
    { who: 'sriku', text: 'With an LSTM, a type of recurrent network with a memory cell. The forget gate is the part of the cell that regulates the flow of information, deciding which information to discard from the cell state.' },
    { who: 'sundu', text: 'So it forgets on purpose.' },
    { who: 'sriku', text: 'To keep the context that matters. Without that, the cell would just hoard everything.' },
  ]}
/>

<Gif
  name="forget-gate"
  alt="The sentence The cat, which ate quickly, was hungry is shown with five memory cells: cat, which, ate, quickly and was. The cells for which, ate and quickly are crossed out by the forget gate, while cat and was stay lit. This is a toy sketch."
  caption="Fig. 58: Toy sketch. Keep the subject, drop the filler."
/>

<Convo
  lines={[
    { who: 'sundu', text: 'Was the gate always in LSTMs?' },
    { who: 'sriku', text: 'No. The first LSTM had a weakness with continual input streams that are not split into marked sequences. Without resets, Gers, Schmidhuber and Cummins say the cell’s state may grow indefinitely and eventually cause the network to break down.' },
    { who: 'cherry', text: 'And their fix?' },
    { who: 'sriku', text: 'A novel, adaptive "forget gate" that lets an LSTM cell learn to reset itself at appropriate times. On continual versions of benchmark problems, every algorithm failed, including the plain LSTM. LSTM with forget gates solved them.' },
    { who: 'sundu', text: 'Used in anything big?' },
    { who: 'sriku', text: 'Google researchers used LSTM networks to train acoustic models for large-vocabulary speech recognition, and reported state-of-the-art performance from relatively small models.' },
  ]}
/>

<CaseStudy
  title="Learning to forget (Gers, Schmidhuber and Cummins, 2000)"
  stats={[
    { value: 'Unbounded', label: 'State growth without resets, until breakdown' },
    { value: 'All failed', label: 'Continual benchmarks, including plain LSTM' },
    { value: 'Solved', label: 'Same benchmarks, LSTM with forget gates' },
  ]}
  winner="The authors’ remedy: “a novel, adaptive ‘forget gate’ that enables an LSTM cell to learn to reset itself at appropriate times, thus releasing internal resources.”"
  takeaway="A memory that cannot let go eventually breaks. Good memory includes deciding what to drop."
  source={[
    {
      text: 'Gers, Schmidhuber and Cummins, “Learning to Forget: Continual Prediction with LSTM”, Neural Computation, 2000.',
      href: 'https://doi.org/10.1162/089976600300015015',
    },
    {
      text: 'Sak, Senior and Beaufays (Google), “Long Short-Term Memory Based Recurrent Neural Network Architectures for Large Vocabulary Speech Recognition”, 2014. Free on arXiv.',
      href: 'https://arxiv.org/abs/1402.1128',
    },
  ]}
/>

**Real definition:** the portion of a Long Short-Term Memory cell that regulates the flow of information through the cell. Forget gates maintain context by deciding which information to discard from the cell state. [Google’s glossary: forget gate ↗](https://developers.google.com/machine-learning/glossary#forget-gate)

## Chai-Stall Recap

| Term | The chai-stall version | Plain meaning |
| --- | --- | --- |
| Feature cross | Freezing and windy is its own thing | Combine features into one new feature |
| Federated learning | The model travels, the data stays | Train on devices, share only updates |
| Feedback loop | The model feeds itself | Predictions shape the next training data |
| Few-shot prompting | Show, then ask | Put several examples in the prompt |
| Fine-tuning | Pre-train wide, then specialise | A second training pass for one task |
| Foundation model | One base, many buildings | A big pre-trained base for many uses |
| False positive rate | Healthy people wrongly flagged | Share of negatives called positive |
| Forget gate | Remember what matters | The LSTM part that discards old context |
