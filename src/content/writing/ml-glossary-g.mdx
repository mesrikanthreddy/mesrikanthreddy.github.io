<Convo

**Real definition:** a GAN is a system to create new data in which a generator creates data and a discriminator determines whether that created data is valid or invalid. [Google’s glossary: GAN ↗](https://developers.google.com/machine-learning/glossary#gan)

## Chai-Stall Recap

| Term | The chai-stall version | Plain meaning |
| --- | --- | --- |
| GAN | The forger and the detective | A generator and a discriminator train against each other |
| Generalization | Learning, not memorising | Doing well on data it has not seen |
| Generative model | Make new examples | Creates new data like its training data |
| Gemma | Google’s open models | Lightweight open models from Gemini research |
| Gradient boosted trees | The spreadsheet champion | Trees that fix the previous trees’ mistakes |
| Generative agents | The party that planned itself | LLM agents with personas, memory and routines |
| Grounding | Show your source | Base the answer on trusted retrieved information |
| Ground truth | What actually happened | The real answer a prediction is compared with |
| Guardrails | A bouncer on both doors | Checks that prevent harm |
