## WALS: Every Guess Comes With a Confidence

<Convo
  lines={[
    { who: 'cherry', text: 'Matrix factorization from Part M assumes people rate things. My users never rate anything. They just watch.' },
    { who: 'sriku', text: 'Then use Weighted Alternating Least Squares. WALS is an algorithm for minimizing the objective function during matrix factorization in recommendation systems, and it lets you downweight the missing examples. It minimizes the weighted squared error between the original matrix and the reconstruction by alternating between fixing the row factorization and fixing the column factorization.' },
    { who: 'sundu', text: 'Each half is a least squares problem.' },
    { who: 'sriku', text: 'Right. Hold the users fixed and solve for the items, then hold the items fixed and solve for the users, and keep taking turns.' },
  ]}
/>

<Gif

Beside it, a users column and an items row take turns being highlighted as the algorithm alternates between solving for users with items fixed and for items with users fixed. Text explains that watched means positive preference and unknown means weak negative preference, each with its own confidence."
  caption="Fig. 141: Toy watch history. Alternate between solving for users and items."
/>

<Convo
  lines={[
    { who: 'sundu', text: 'Who wrote the paper that made this popular?' },
    { who: 'sriku', text: 'Hu, Koren and Volinsky, in Collaborative Filtering for Implicit Feedback Datasets. Implicit feedback means systems passively track behaviour such as purchase history, watching habits and browsing activity. There is no direct input from users about their preferences, and no strong evidence about which products they dislike.' },
    { who: 'cherry', text: 'So what is the model?' },
    { who: 'sriku', text: 'They propose treating the data as an indication of positive and negative preference associated with vastly varying confidence levels. That leads to a factor model tailored to implicit feedback recommenders.' },
    { who: 'sundu', text: 'Does it scale?' },
    { who: 'sriku', text: 'They suggest a scalable optimization procedure that scales linearly with the data size. The algorithm was used successfully within a recommender system for television shows, and they say it compares favorably with well-tuned implementations of other known methods.' },
  ]}
/>

<Convo

    { who: 'cherry', text: 'Why is it hard for a machine?' },

    { who: 'sriku', text: 'The WinoGrande paper says the original set has 273 expert-crafted problems, and recent neural language models had reached around 90% on variants of it. The best methods there got 59.4 to 79.1%, which is 15 to 35 points below human performance of 94.0%.' },
  ]}

<Convo

## Word Embedding: Meaning as Geometry

  lines={[
    { who: 'cherry', text: 'How does a model know that carrot and celery are related but carrot and airplane are not?' },

Google’s example is carrots, celery and cucumbers, which end up relatively close to each other and far from airplanes and sunglasses.' },
    { who: 'sundu', text: 'This is the embedding space from Part E.' },

<Convo
  lines={[
    { who: 'sundu', text: 'Which paper is it?' },
    { who: 'sriku', text: 'GloVe, by Pennington, Socher and Manning at Stanford, EMNLP 2014. They start from the observation that earlier methods captured fine-grained semantic and syntactic regularities with vector arithmetic, but the origin of those regularities had remained opaque.' },
    { who: 'cherry', text: 'And what is new?' },
    { who: 'sriku', text: 'A global log-bilinear regression model that combines the two major families, global matrix factorization and local context window methods.     { who: 'sundu', text: 'Results?' },

  ]}
/>

<CaseStudy

**Real definition:** representing each word in a word set within an embedding vector; that is, representing each word as a vector of floating-point values. Words with similar meanings have more-similar representations than words with different meanings. [Google’s glossary: word embedding ↗](https://developers.google.com/machine-learning/glossary#word-embedding)

| Term | The chai-stall version | Plain meaning |
