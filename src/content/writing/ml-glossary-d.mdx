## Differential Privacy: Hide in the Noise

<Convo
  lines={[

    { who: 'sundu', text: 'So my data is in there, but blurred.' },
    { who: 'sriku', text: 'Blurred enough that the result looks about the same whether you are in the data or not.' },

  caption="Fig. 38: Toy counts. With noise, one person’s presence disappears."

<Convo
  lines={[

<CaseStudy
  title="RAPPOR in Chrome (Google, 2014)"

    { value: '~14 million', label: 'Opted-in respondents, daily collection' },

**Real definition:** in machine learning, an anonymization approach to protect sensitive data in a model’s training set from being exposed, by sampling and adding noise during training to obscure individual data points. ## Dropout Regularization: Nobody Gets to Rely on a Friend

<Convo
  lines={[
    { who: 'cherry', text: 'My network aced training and flopped on new data.' },
    { who: 'sriku', text: 'Overfitting. One cure is dropout regularization: at each training step, remove a random selection of units in a layer.' },
    { who: 'sundu', text: 'Why would breaking the network help?' },
    { who: 'sriku', text: 'No unit can lean on a particular neighbour, because the neighbour might be gone this step. Each one has to be useful on its own.' },
    { who: 'cherry', text: 'Like a team where anyone might be absent on match day.' },
  ]}
/>

<Gif
  name="dropout"
  alt="A small network is drawn six times. Each time a different random set of units is crossed out and their connections disappear, while the remaining units stay lit."
  caption="Fig. 41: A different random set is switched off at every step."
/>

<Convo
  lines={[
    { who: 'sundu', text: 'Where did that idea come from?' },
    { who: 'sriku', text: 'Hinton’s group, in 2012. When a big network is trained on a small training set, it typically performs poorly on held-out data. They reduced that by randomly omitting half of the feature detectors on each training case.' },
    { who: 'cherry', text: 'The reason?' },
    { who: 'sriku', text: 'It prevents complex co-adaptations, where a detector is only useful alongside several specific others. They reported big improvements on many benchmarks and new records for speech and object recognition.' },
    { who: 'sundu', text: 'It showed up again in AlexNet.' },
    { who: 'sriku', text: 'Yes. AlexNet used dropout in its fully connected layers, which its authors say proved very effective.' },
  ]}
/>

<CaseStudy
  title="Dropout (Hinton et al., 2012)"
  stats={[
    { value: '50%', label: 'Feature detectors omitted per training case' },
    { value: 'Records', label: 'Set for speech and object recognition' },
  ]}
  winner="The abstract: “Random ‘dropout’ gives big improvements on many benchmark tasks and sets new records for speech and object recognition.”"
  takeaway="Training with parts of the network missing made the whole network sturdier."
  source={{
    text: 'Hinton et al., “Improving neural networks by preventing co-adaptation of feature detectors”, 2012. Free on arXiv.',
    href: 'https://arxiv.org/abs/1207.0580',
  }}
/>

**Real definition:** a form of regularization useful in training neural networks that removes a random selection of a fixed number of the units in a network layer for a single gradient step. The more units dropped out, the stronger the regularization. [Google’s glossary: dropout regularization ↗](https://developers.google.com/machine-learning/glossary#dropout-regularization)
